Technical Architecture & Systems Documentation

Altalis — Systems Deep Dive

Author: Omar Ginza (Project Manager & Unity Programmer) Studio: Fiz Studio (6 Members) Engine: Unity / C# Release: Public Steam Demo

Altalis is a 2D puzzle Metroidvania built around systemic world manipulation. Instead of treating rooms as static platforming obstacle courses, players can slow down time, select physical blocks on a grid, and copy, cut, fuse, or launch them across gaps. Below is a concise breakdown of the four core C# architectures I engineered to make those mechanics feel responsive, deterministic, and seamless across an interconnected map.

System 01 · Core Gameplay Loop

Object Manipulation Engine (Selection Mode)

The signature mechanic of Altalis lets players toggle into Selection Mode at any moment—even mid-jump. To make grid editing feel fair during live platforming, entering Selection Mode smoothly dilates game time to 0.3x and locks player locomotion while activating a perspective-correct grid cursor.

Mode State & Time Dilation GameModeManager.cs

Switches between Movement and Selection modes. Interpolates Time.timeScale down to 0.3f using unscaled delta time so animations and physics slow down smoothly without freezing UI responsiveness.

Hybrid Mouse & Gamepad Grid Cursor GridCursor.cs

Projects screen input onto the gameplay Z-plane via raycast math and snaps to Unity grid cell centers. Automatically switches between raw mouse position and deadzone-filtered gamepad stick movement.

Bounding-Box Hit Detection GridSelection.cs

Supports both single-tap (OverlapPoint) and drag-box (OverlapAreaAll) selection for objects tagged "Selectable". Enforces the player's max selection limit and triggers camera-shake feedback if exceeded.

Ghost Preview & Copy/Cut Paste CopyPlacement.cs

Spawns translucent green/red ghost clones offset from a primary snap pivot. Validates wall/enemy collisions (OverlapBoxAll) and mana availability before instantiating physical rigidbodies or shrinking cut originals.

System 02 · Modular Skills & Physics Fusion

Dynamic Block Merging & Radial Skill Wheel

Rather than coupling ability logic to the player controller, every skill inherits from an abstract Skill base contract and is dynamically loaded into a radial wheel centered on the player's grid cursor.

Runtime Physics Fusion & Launch LaunchSelection.cs

Merges selected blocks into a single CombinedLaunchObject with mass scaled by block count. Upon hitting a wall, LaunchCollisionHandler unmerges the composite collider back into individual falling blocks.

Rideable Projectile Sync PlatformPlayerSync

Allows players to jump onto their own launched blocks mid-air. Temporarily parents the player and synchronizes horizontal velocity so players can ride moving projectiles across wide chasms.

Cursor-Centered Radial Wheel SkillWheelController.cs

Opens directly at the active grid cell center and computes atan2(dx, dy) from wheel origin to cursor/stick to highlight and trigger equipped abilities on release.

Modular Skill Loadout SkillManager.cs

Instantiates equipped skill prefabs (Launch, Hammer, Shield) as child components and routes slot activations cleanly without monolithic switch statements.

System 03 · State Persistence & Instant Rollback

Two-Tier Checkpoints & Scene-Free Puzzle Undo

In a puzzle-heavy game, forcing a full Unity scene reload every time a player misplaces a block or touches spikes ruins pacing. I designed a distributed JSON save architecture that separates combat death from local puzzle resets.

Trigger / Event Recovery Tier Snapshot Source What Happens in Engine
HP Reaches Zero (Combat) Global Respawn save.json (Campfire Checkpoint) Reloads checkpoint scene, restores full HP & Mana, and places player at the last campfire.
Spikes / Magma (Hazard) Local Room Reset save_manaBlock_{id}.json No scene reload. Reconstructs placed blocks and player position at the room's Mana Block.
Hold Undo (1.5s) Instant Puzzle Rollback save_manaBlock_{id}.json Plays a dissolve shader over placed blocks, refills Mana, and restores the room snapshot in place.
Dynamic Prefab Reconstruction SaveSystem.cs

Tracks every runtime-copied or moved object via PrefabID.cs. On rollback, destroys modified instances and re-instantiates exact prefabs with saved transforms from the prefab catalog.

Localized Puzzle Snapshots ManaBlock.cs & UndoManager.cs

Stepping on a Mana Block writes a lightweight room snapshot. Holding the Undo key fills a 1.5s radial progress ring (locked out during boss fights) to trigger a shader-dissolve reset.

System 04 · Metroidvania World Architecture

Room Discovery, Fog-of-War Map & Gating

Altalis connects dozens of rooms through bidirectional portals, levers, and ability-gated doors. Every room transition and environmental switch commits its state to dedicated JSON files so the world remembers player actions permanently.

Persistent Map & Fog of War MapManager.cs & MapRoomUI.cs

DontDestroyOnLoad singleton tracking discovered rooms in map_only.json. Updates map tile alpha dynamically (0 = hidden, 0.5 = active room, 1.0 = visited) and auto-centers the pan/zoom map camera.

Portal Transitions & Object Carryover NextSceneTrigger.cs

Pairs entrance and exit portals via portalID. Saves placed room objects prior to scene unload, animates player entry/exit movement, and coordinates spawn handoff with GameModeManager.

Deterministic Switch & Gate IDs LeverController.cs & GateController.cs

Levers, gates, and chests generate deterministic IDs (via PrefabID or world coordinates) stored in activatable_states_{scene}.json so opened shortcuts stay open forever.

Permanent Upgrade Transactions ResourceManager.cs

Provides transaction-safe mana spending (TrySpendMana()) and persists permanent capacity upgrades (Max Mana and Grid Selection Limit) to resource_only.json.
